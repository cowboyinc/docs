# Erlang Cowboy Demo

This gallery demo is an Erlang actor-model comparison project. It is not part
of the Python actor curriculum and is not included in the default example
sweep.

## Files

- `src/` — Erlang demo modules
- `rebar.config` — Erlang build configuration
- `Makefile` — local build entrypoint

## Caveats

- Build output is intentionally ignored and should not be committed.
- Use this as a runtime comparison reference, not as a first Cowboy lesson.
