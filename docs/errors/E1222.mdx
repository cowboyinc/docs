# E1222 — Target account does not exist

| Property | Value |
|----------|-------|
| **Code** | `1222` |
| **Slug** | `E1222` |
| **Category** | `runtime` (Runtime) |


## What happened

Target account does not exist.

## Why it happened

The referenced account has not been created on-chain.

## How to fix

Create or fund the account before referencing it.
