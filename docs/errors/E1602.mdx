# E1602 — Runner not found

| Property | Value |
|----------|-------|
| **Code** | `1602` |
| **Slug** | `E1602` |
| **Category** | `runner` (Runner / Consensus) |
| **CIP** | CIP-2 |

## What happened

Runner not found.

## Why it happened

The runner address is not registered in the runner registry.

## How to fix

Register the runner with sufficient stake before taking jobs.
