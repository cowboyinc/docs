# E1608 — No consensus reached

| Property | Value |
|----------|-------|
| **Code** | `1608` |
| **Slug** | `E1608` |
| **Category** | `runner` (Runner / Consensus) |
| **CIP** | CIP-2 |

## What happened

No consensus reached.

## Why it happened

Runners returned divergent results and no majority could be established.

## How to fix

Runners returned divergent results. Consider simplifying the task or using deterministic mode.
