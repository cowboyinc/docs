# E1225 — Duplicate message id

| Property | Value |
|----------|-------|
| **Code** | `1225` |
| **Slug** | `E1225` |
| **Category** | `runtime` (Runtime) |


## What happened

Duplicate message id.

## Why it happened

A message with this id was already delivered.

## How to fix

Use a fresh message id.
