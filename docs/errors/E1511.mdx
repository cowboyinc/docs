# E1511 — Commit window closed

| Property | Value |
|----------|-------|
| **Code** | `1511` |

| **Category** | `commit_reveal` (Commit-Reveal) |


## What happened

Commit window closed.

## Why it happened

The commitment deadline has passed.

## How to fix

Commit before the deadline block. Submit this work in a future round.
