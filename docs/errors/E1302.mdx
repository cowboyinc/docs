# E1302 — Invalid manifest

| Property | Value |
|----------|-------|
| **Code** | `1302` |
| **Slug** | `E1302` |
| **Category** | `entitlement` (Entitlement) |


## What happened

Invalid manifest.

## Why it happened

The entitlement manifest has invalid syntax or does not conform to the schema.

## How to fix

Fix manifest syntax and shape against the entitlements schema.
