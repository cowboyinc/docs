# E1227 — Persistent store error

| Property | Value |
|----------|-------|
| **Code** | `1227` |
| **Slug** | `E1227` |
| **Category** | `internal` (Internal) |


## What happened

Persistent store error.

## Why it happened

The persistent storage backend encountered an error.

## How to fix

Retry the transaction. Report with the tx hash if it persists.
