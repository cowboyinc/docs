# E1512 — Reveal window not yet open

| Property | Value |
|----------|-------|
| **Code** | `1512` |
| **Slug** | `E1512` |
| **Category** | `commit_reveal` (Commit-Reveal) |


## What happened

Reveal window not yet open.

## Why it happened

The reveal phase has not started yet.

## How to fix

Wait until the reveal window opens before submitting a reveal.
