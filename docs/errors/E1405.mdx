# E1405 — Token account is frozen

| Property | Value |
|----------|-------|
| **Code** | `1405` |
| **Slug** | `E1405` |
| **Category** | `token` (Token (CIP-20)) |
| **CIP** | CIP-20 |

## What happened

Token account is frozen.

## Why it happened

The token account has been frozen by the token administrator.

## How to fix

Contact the token authority to unfreeze the account.
