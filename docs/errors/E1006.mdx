# E1006 — Out of cells

| Property | Value |
|----------|-------|
| **Code** | `1006` |
| **Slug** | `E1006` |
| **Category** | `gas` (Gas) |
| **CIP** | CIP-3 |

## What happened

Out of cells.

## Why it happened

The transaction consumed more storage cells than the `cells_limit` allows.

## How to fix

Increase `cells_limit` or reduce state writes / returned data size.

```json
{
  "code": 1006,
```
