# E1603 — Insufficient stake

| Property | Value |
|----------|-------|
| **Code** | `1603` |
| **Slug** | `E1603` |
| **Category** | `runner` (Runner / Consensus) |
| **CIP** | CIP-2 |

## What happened

Insufficient stake.

## Why it happened

The runner's staked amount is below the minimum required for the operation.

## How to fix

Top up the runner's stake to at least `MIN_STAKE × 1.5` per active job.
