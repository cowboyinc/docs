# E1606 — Runner not assigned to job

| Property | Value |
|----------|-------|
| **Code** | `1606` |
| **Slug** | `E1606` |
| **Category** | `runner` (Runner / Consensus) |
| **CIP** | CIP-2 |

## What happened

Runner not assigned to job.

## Why it happened

This runner was not selected for the specified job.

## How to fix

This runner cannot submit a result for this job.
