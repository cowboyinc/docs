# E1226 — Target mailbox is full

| Property | Value |
|----------|-------|
| **Code** | `1226` |
| **Slug** | `E1226` |
| **Category** | `runtime` (Runtime) |


## What happened

Target mailbox is full.

## Why it happened

The target actor's mailbox has reached its maximum capacity (1,000 messages).

## How to fix

Drain the mailbox or reduce the send rate.
