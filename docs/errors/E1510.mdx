# E1510 — Commitment mismatch

| Property | Value |
|----------|-------|
| **Code** | `1510` |
| **Slug** | `E1510` |
| **Category** | `commit_reveal` (Commit-Reveal) |


## What happened

Commitment mismatch.

## Why it happened

The revealed value does not hash to the stored commitment.

## How to fix

Re-commit with the correct value, or correct the reveal to match the commitment.
