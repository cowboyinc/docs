# E1008 — Basefee too low

| Property | Value |
|----------|-------|
| **Code** | `1008` |
| **Slug** | `E1008` |
| **Category** | `gas` (Gas) |
| **CIP** | CIP-3 |

## What happened

Basefee too low.

## Why it happened

The transaction's `max_fee_per_cycle` or `max_fee_per_cell` is below the current block basefee.

## How to fix

Raise `max_fee_per_cycle` and `max_fee_per_cell` above the current basefee (query via RPC).
