# E1214 — Serialization failure

| Property | Value |
|----------|-------|
| **Code** | `1214` |
| **Slug** | `E1214` |
| **Category** | `internal` (Internal) |


## What happened

Serialization failure.

## Why it happened

CBOR or internal serialization failed.

## How to fix

Retry the transaction. Report if the error persists.
